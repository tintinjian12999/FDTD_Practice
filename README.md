# uFDTD

## 繁體中文

uFDTD 是依據 John B. Schneider《Understanding the Finite-Difference
Time-Domain Method》規劃的原生 Windows C 語言 FDTD 學習與開發專案。

目前狀態：環境設計已核准，工具鏈尚未安裝。預定使用 Conda、GCC、
CMake、Ninja、winpthreads、Microsoft MPI、NumPy 與 Matplotlib。

## English

uFDTD is a native Windows C learning and development project based on John B.
Schneider's *Understanding the Finite-Difference Time-Domain Method*.

Current status: the environment design is approved, but the toolchain has not
yet been installed. The planned stack uses Conda, GCC, CMake, Ninja,
winpthreads, Microsoft MPI, NumPy, and Matplotlib.
